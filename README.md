# ESP32 Blink Challenge

## Problem Statement

Blink the ESP32's built-in LED at 1-second intervals and simulate the program in Wokwi before testing it on hardware.

## Objective

To understand basic GPIO output using the ESP32.

## Components

- ESP32 DevKitC V4
- Built-in LED

## Working

The program configures GPIO 2 as an output and repeatedly:

1. Turns the LED ON for 1 second.
2. Turns the LED OFF for 1 second.

## Code

The implementation is provided in `blink.ino`.

## Wokwi Simulation

The program was tested using Wokwi before hardware implementation.

## Result

The LED is programmed to blink at 1-second intervals.
